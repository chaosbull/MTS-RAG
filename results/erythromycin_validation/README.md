# Erythromycin validation outputs

Figures, tables, and step dumps from `run_erythromycin.py` on plant erythromycin batches (2000+). Raw Excel files are not in this repository.

| Path | Contents |
|------|----------|
| [`validation_report.md`](validation_report.md) | Metric summary |
| [`figures/`](figures/) | Plots |
| [`tables/`](tables/) | CSV exports |
| [`steps/`](steps/) | Per-step dumps |

Rerun with `python run_erythromycin.py` after pointing `UDCF_DATA_DIR` (or `data/erythromycin/`) at the plant Excel folder.
